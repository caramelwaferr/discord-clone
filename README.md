# Discord Clone

This app uses networking and concurrency to have a functioning chatroom which multiple users from various locations can chat to each other in real time.

Some of the features include video calls, live streaming, sending images/gifs, changing usernames, checking number of people in a chatroom, and switching chatrooms while allowing concurrent chat histories in each chatroom, allowing people to join and leave at will without missing any of the conversations.
